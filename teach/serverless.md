# Serverless Needs
- deploy on any cloud vendor's serverless infrastructure for high-volatility, unpredictable load
- deploy on a fully controlled / managed serverless runtime
    - this one should be able to be deployed locally, on-promise or on any cloud vendor at a lower level
    - it should likely be cheaper for sustained, well understood loads, than serverless infrastuctures, without changing the approach
- use the fully controlled serverless runtime for local development
